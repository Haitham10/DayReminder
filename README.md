# DayReminder

A modern Android calendar and reminder application built with Kotlin and Jetpack Compose.

## Overview

DayReminder is a calendar-based reminder application that allows users to select a date and create reminders for specific times.

The project is being developed as a portfolio project with a focus on modern Android development practices, clean architecture, testing, and maintainable code.

## Tech Stack

- Kotlin
- Jetpack Compose
- MVVM
- Hilt
- Room Database
- Coroutines
- Flow
- JUnit
- Compose UI Testing

## Architecture

The application follows a layered architecture:

UI → ViewModel → Use Cases → Repository → Room

Dependency injection is handled using Hilt.

## Current Status

🚧 In development

The project is currently being built step by step, with features and architecture being added incrementally.

## Planned Features

- Calendar interface
- Create and manage reminders
- Date and time selection
- Local reminder storage
- Reminder notifications
- Input validation
- Unit testing
- Compose UI testing
